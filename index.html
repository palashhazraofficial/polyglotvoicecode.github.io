About

Polyglot VoiceCode is a desktop application that allows you to type using your voice. It supports offline speech recognition using [vosk] (https://alphacephei.com/vosk/), means your privacy and reliability are on top.

Features

🎤 Offline voice typing (no internet required)

🌐 Supports 20+ languages (Arabic, Hindi, English, Japenese, Korean and more)

🤍 Modern light theme status window

⌨ Toggle with hotkeys (Ctrl + Alt + V)

💻 Works in any text field across applications

Requirements

🖥 Windows 10/11 (64-bit)

🎤 Microphone access

Installation

1. Download the installer ('Polyglot_VoiceCode_X_Setup.exe') from the official website

2. Run the installer and follow the on-screen instructions

3. Launch the application from the Start Menu

Usage

1. Press Ctrl + Alt + V to start or stop voice typing mode

2. Speak clearly into your microphone

3. The recognized text will appear in the active text field where the cursoe blinks
